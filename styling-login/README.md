# Microsoft Login Branding Assets

This folder contains branding assets for the Entra External ID login screens.

## How to Apply These in Azure Portal

1. Go to: https://entra.microsoft.com
2. Switch to **ACDCRegistration** tenant
3. Navigate to: **User experiences** → **Company branding**
4. Click **Configure** or **Edit**
5. Upload each file as described below

---

## Asset Specifications

### 1. Background Color
- **Value**: `#1a365d` (Arctic dark blue)
- **Alternative**: `#0f172a` (Darker slate)
- Just enter the hex code in the portal

### 2. Background Image (`background.jpg`)
- **Size**: 1920 x 1080 pixels (recommended)
- **Max file size**: 300 KB
- **Format**: JPG, PNG, or GIF
- **Tips**: Use a snowy mountain or aurora image

### 3. Favicon (`favicon.ico`)
- **Size**: 32 x 32 pixels (or 16x16)
- **Format**: ICO, PNG
- **Max file size**: 5 KB

### 4. Banner Logo (`banner-logo.png`)
- **Size**: Max 280 x 60 pixels
- **Format**: PNG (transparent background recommended)
- **Max file size**: 50 KB
- **Usage**: Appears at top of sign-in page

### 5. Square Logo - Light Theme (`square-logo-light.png`)
- **Size**: 240 x 240 pixels (recommended)
- **Format**: PNG
- **Max file size**: 50 KB
- **Usage**: Shown on light backgrounds

### 6. Square Logo - Dark Theme (`square-logo-dark.png`)
- **Size**: 240 x 240 pixels (recommended)
- **Format**: PNG
- **Max file size**: 50 KB
- **Usage**: Shown on dark backgrounds

### 7. Custom CSS (`custom-styles.css`)
- **Max file size**: 25 KB
- **Note**: Limited CSS properties are supported
